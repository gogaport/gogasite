autounattend.xml — Чистая Windows 10 & 11 Pro
Скачать XML (29 КБ) Просмотреть XML ↗
Создает локального админа Admin без пароля и учетки Microsoft, обходит проверки TPM 2.0 / Secure Boot / RAM, вырезает Copilot, Recall, Cortana, OneDrive и телеметрию, включает темную тему и классическое меню проводника.
Как использовать: скопируй файл в корень загрузочной флешки с Windows (Ventoy или Rufus). Установщик применит настройки автоматически.
