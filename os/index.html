Как использовать autounattend.xml
1. Установка с флешки Ventoy (Рекомендуется)
Просто скопируйте файл autounattend.xml в корень вашей флешки Ventoy рядом с ISO-образами Windows. Ventoy автоматически найдет файл конфигурации и применит его при старте установки.
2. Установка со стандартной флешки (Rufus)
Запишите образ Windows 10 или 11 на флешку через Rufus, затем скопируйте autounattend.xml в самый корень готовой флешки. При загрузке с USB установщик Windows автоматически подхватит настройки.
